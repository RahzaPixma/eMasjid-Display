# eMasjid Display

Paparan web ringkas untuk jam solat masjid atau surau.

## Ciri-ciri

- Jam digital masa nyata.
- Tarikh semasa dalam Bahasa Melayu.
- Senarai waktu solat Subuh, Zohor, Asar, Maghrib, dan Isyak.
- Kiraan masa untuk solat seterusnya.
- Carian waktu solat mengikut bandar/negara atau lokasi semasa.

## Cara guna

Buka `index.html` dalam pelayar web moden. Sambungan internet diperlukan untuk mendapatkan waktu solat daripada API Aladhan.
