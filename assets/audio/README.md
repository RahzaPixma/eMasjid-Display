# Folder Audio

Letakkan fail audio custom di sini.

Nama fail default yang digunakan oleh admin:

- `azan-subuh.mp3` untuk azan Subuh.
- `azan.mp3` untuk Zohor, Asar, Maghrib, dan Isyak.
- `iqamat.mp3` untuk iqamat.

Masukkan path seperti `assets/audio/azan-subuh.mp3`, `assets/audio/azan.mp3`, dan `assets/audio/iqamat.mp3` di page `admin.html`.
