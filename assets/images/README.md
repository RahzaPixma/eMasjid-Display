# Folder Gambar

Letakkan gambar untuk display dan slideshow di folder ini.

Nama fail default yang dicadangkan:

- `default.png` untuk paparan normal.
- `praying.png` untuk background selepas iqamah / sedang solat.
- gambar lain seperti `slide-1.jpg`, `slide-2.png`, dan seterusnya untuk slideshow.

Masukkan path gambar di page `admin.html`, satu path setiap baris. Contoh:

```text
assets/images/default.png
assets/images/slide-1.jpg
assets/images/slide-2.png
```
